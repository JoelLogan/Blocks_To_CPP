# Blocks2Cpp user guide

Blocks2Cpp is a Scratch-style editor for Windows and Linux: you snap blocks
together, it turns them into real, readable C++, compiles that C++ with the
g++ already on your computer, and runs the program in a built-in console.

This guide is for the people who use it: learners, teachers and anyone who
wants to write C++ with blocks.

| Page                                  | What it covers                                                                                                                          |
| ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| [Getting started](getting-started.md) | The first start, setting up g++, a tour of the window, building and running a guessing game, saving, Restricted Mode, settings and keys |

The guide grows with the app. It describes the desktop editor of milestone M2;
tutorials, the full guide and the offline help that the app opens from its
_Help_ menu come with milestone M5
([roadmap](../spec/10-roadmap.md#101-milestones)).
